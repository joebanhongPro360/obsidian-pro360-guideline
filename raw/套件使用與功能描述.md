## Packages

| **套件名稱**         | **功能描述**                         |
| ---------------- | -------------------------------- |
| react-loadable   | 分割代碼的React高階元件。                  |
| isomorphic-fetch | 提供一致的**`fetch`** API的實現。         |
| Stylus           | CSS預處理器，增加變數、混合等功能。              |
| lodash           | 實用工具庫，方便處理數組、數字等。                |
| elevio           | 提供用戶支援和教育資源的客戶服務平台。              |
| raven.js         | 自動報告網頁應用錯誤的Sentry JavaScript客戶端。 |
| react-css-module | 模組化方式使用CSS的React庫。               |
| lazyload.js      | 延遲載入圖片和資源以提高頁面效率的腳本。             |
| babel            | 將ES6代碼轉為向下兼容的JavaScript編譯器。      |
| Styled-component | 使用模板字符串創建樣式化React組件的庫。           |
| Zendesk          | 處理用戶查詢的客戶服務和支援票務平台。              |
| Drift (for pro)  | 提供聊天機器人和即時通訊的對話行銷平台。             |
| Beamer (for pro) | 產品更新通知工具，提高用戶參與度。                |
| Hotjar           | 追蹤用戶行為和收集回饋的網站分析工具。              |
| i18next          | 國際化框架，幫助將你的網站或應用翻譯成多種語言。         |
| next-i18next     | 為Next.js應用提供簡易的國際化(i18n)支持的插件。   |
| Day.js           | 輕量的日期處理庫，提供簡潔的API來解析、驗證、操作和顯示日期。 |
