## Versioning Rule

### Version Format
- 版本號格式：`{大版本}.{中版本}.{更新版本}`
- 英文對應待補：是否等同 semantic versioning 的 `major.minor.patch`

### 大版本
- 變更時機：產品有重要功能、架構或商業模式變更時
- 影響範圍：待補

### 中版本
- 變更時機：產品有新功能提供，因此需要透過 API Key 進行版本更新管理
- 影響範圍：API Key 管理與功能版本控管

### 更新版本
- 變更時機：畫面微調、參數微調，或 Bug 修正等不影響功能的更新
- 影響範圍：不影響功能的更新

### API Key Update Rule
- API Key 的更換會依照「中版本」進行 update。
- 待補：API Key update 的負責角色、操作流程、驗證方式與發版注意事項。
