# 前端架構地圖

## Architecture Areas

- Framework：[[前端套件與第三方服務]] 記錄 React / Next.js 相關套件線索；實際 framework 使用範圍待補。
- Routing：待補
- State management：待補
- API layer：[[環境與 API 文件]] 記錄新版與舊版 API 說明文件入口；實際 API layer 實作待補。
- Design system / UI components：[[前端套件與第三方服務]] 記錄 Styling 相關套件線索；實際 design system 待補。
- Form handling：待補
- i18n：[[前端套件與第三方服務]] 記錄 i18next 與 next-i18next。
- Testing：待補
- Build and deployment：[[前端套件與第三方服務]] 記錄 babel；實際 build pipeline 待補。
- Observability：[[前端套件與第三方服務]] 記錄 raven.js、Hotjar 等第三方服務線索。

## Learning Path

1. 先確認主要 frontend repository 與 application。
2. 找出入口檔、routing、layout 與主要 feature modules。
3. 補上狀態管理、API 呼叫、權限處理與設計系統的連結。
4. 把常見修改點連回 [[工作流程地圖]]。
