# 前端知識庫總覽

這個 vault 用來建立公司前端知識的 AI 維護型 wiki。目標不是一次寫完所有文件，而是透過持續匯入來源、整理頁面與建立連結，逐步累積對專案、產品、架構與流程的理解。

## Goals

- 幫助新接觸專案的人快速理解前端工作脈絡。
- 建立 [[產品地圖]]、[[前端架構地圖]]、[[工作流程地圖]] 之間的關聯。
- 讓未來查詢時能快速回答「某個產品或功能牽涉哪些前端工作」。
- 將零散筆記轉成可搜尋、可連結、可持續更新的 wiki。

## Knowledge Layers

- `raw/`：原始資料。包含人工筆記、文件摘錄、會議紀錄、PR/Issue 摘要等。
- `wiki/`：LLM 整理後的知識頁。這一層會被持續更新與交叉連結。
- [[index]]：查詢入口與內容目錄。
- [[log]]：追加式維護紀錄。
- [[AGENTS|AGENTS]]：LLM 維護 wiki 時要遵守的規範。

## First Reading Path

1. 先讀 [[產品地圖]]，理解有哪些產品與使用者面向。
2. 再讀 [[前端架構地圖]]，理解前端技術與專案結構。
3. 接著讀 [[工作流程地圖]]，理解日常開發、審查、測試與發版方式。
4. 遇到不熟悉的名詞，補到 [[術語表]]。

## Current State

## Useful Query Patterns

- 「我要熟悉某個產品，應該先看哪些前端頁面？」
- 「某個功能牽涉哪些前端模組、API 與測試？」
- 「目前前端開發流程有哪些步驟？」
- 「這個技術概念在哪些產品或功能中出現？」
- 「哪些資訊仍然是待補？」
